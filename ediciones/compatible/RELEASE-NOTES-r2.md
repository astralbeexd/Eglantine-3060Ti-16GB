# Compatible x86-64-v2 r2 — experimental

Procesadores Intel/AMD x64 con x86-64-v2; objetivo Windows 10 1809+ y Windows 11. Arranque probado solo en Windows 11 con Ryzen 7 5800X.

- Compilacion separada de Zen 3, con deteccion de instrucciones en ejecucion.
- Lanzador con comprobacion de requisitos, argumentos Unicode y entorno limpio.
- Conserva los directorios predeterminados cuando no se configuran rutas personalizadas.
- No se garantiza rendimiento, ausencia de errores ni seguridad absoluta. Xeon, Windows 10 y carrera completa pendientes.

Extrae el ZIP completo en una carpeta nueva y corta; abre Iniciar.cmd. No mezcles sus DLL con Zen 3. No requiere MSYS2 ni administrador.

El ZIP no incluye juegos, claves ni firmware. Aporta solo archivos que tengas derecho a utilizar. Se conservan creditos y licencias originales. Modificaciones preparadas con asistencia de IA; no es una reescritura completa. Las pruebas humanas anteriores no validan esta recompilacion.
