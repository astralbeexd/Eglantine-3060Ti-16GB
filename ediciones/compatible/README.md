# Edición compatible x86-64-v2

Compilada para una gama más amplia de Intel y AMD x64. Objetivo: Windows 10 1809+ y Windows 11. Arranque probado en Windows 11 / Ryzen 7 5800X; Xeon y Windows 10 pendientes.

**[Descargar Eglantine-Compatible-x64-r2.zip](https://github.com/astralbeexd/Eglantine-3060Ti-16GB/releases/download/v1.0.0-compatible-x64-r2/Eglantine-Compatible-x64-r2.zip)** · [Release, hashes e informe antivirus](https://github.com/astralbeexd/Eglantine-3060Ti-16GB/releases/tag/v1.0.0-compatible-x64-r2).

Extrae el ZIP completo en una carpeta nueva y abre Iniciar.cmd o Iniciar-compatible.exe. El lanzador comprueba CPU/Windows y comunica errores de arranque. Una carrera completa con estos binarios sigue pendiente.

La corrección adicional de esta edición conserva los directorios predeterminados cuando la configuración no contiene rutas personalizadas. No reduce la RAM requerida por un juego.
